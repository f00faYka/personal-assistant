# Personal Assistant

A private, voice-first life assistant for two people. The project is currently in repository setup and human-guided discovery; no application architecture or implementation stack has been accepted yet.

## Start here

1. Read [`docs/product-context.md`](docs/product-context.md).
2. Review the current boundaries in [`docs/architecture.md`](docs/architecture.md).
3. Read accepted decisions in [`docs/decisions.md`](docs/decisions.md).
4. Review unresolved questions in [`docs/open-questions.md`](docs/open-questions.md).
5. Select an approved GitHub Issue using [`docs/development-process.md`](docs/development-process.md) and [`docs/github-workflow.md`](docs/github-workflow.md).

The original initialization brief is retained in [`start.md`](start.md) for provenance. The structured documents under `docs/` are the working source of project context.

The proposed initial epics and discovery backlog are preserved in [docs/github-backlog.md](docs/github-backlog.md) pending publication to GitHub.

## Current status
